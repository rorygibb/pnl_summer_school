# pnl_summer_school
This repository contains data and materials for the biodiversity and health sessions in the UCL People & Nature Lab Summer School, 2026.

Key contents: 
↳ data → Contains the data you'll need for the R practical

↳ lecture_slides → Contains a PDF of the slides from the morning lecture

↳ practical → Contains an R workbook and the intro slides from the practical session

## Getting started with the practical

- Open your browser and navigate to https://download-directory.github.io/
- Paste the URL of this web page into the box (https://github.com/rorygibb/pnl_summer_school) which downloads the whole directory
- Find the downloaded zip file in your Downloads folder, and unzip it somewhere sensible
- Open RStudio
- Create a new R script ("New file") and save it into the unzipped pnl_summer_school folder (and call it something sensible)
- Open the R workbook in the "practical" folder (SummerSch_Mosquitoes_Rworkbook.pdf)
- Follow the instructions and copy-paste the code into your script to get started
- Let us know if you have any problems!
